Adventskalender · Admin

Hier siehst du alle 24 Türchen vorab und kannst Comics austauschen. Ohne das Admin-Passwort sind die Comics nur verschlüsselter Datensalat.

Alle Türchen (Vorschau)

„Online“ heißt: Für Besucher schon freigeschaltet. Klick auf ein Bild zeigt es groß.

Comic austauschen

  1. Türchen wählen, neues Comic-Bild (PNG, JPG oder WebP) auswählen, Button klicken. Es wird eine Datei wie tag07.enc heruntergeladen.
  2. Auf GitHub diese Datei in den Ordner comics-enc hochladen (gleicher Name ersetzt den alten Comic) und unten auf Commit changes klicken.
  3. Nach ca. 1–2 Minuten ist die Seite neu gebaut. Ist das Türchen schon offen, sehen Besucher sofort den neuen Comic, sonst erst an seinem Tag.

Das Bild wird nur hier in deinem Browser verschlüsselt, es wird nichts hochgeladen.

Texte ändern

Überschrift, Untertitel und Fußzeile stehen in site/index.html. Auf GitHub mit dem Stift-Symbol bearbeiten und Commit changes klicken, die Seite aktualisiert sich dann von selbst.

Den Bauvorgang siehst du unter Actions. Dort kannst du mit Run workflow auch jederzeit von Hand neu veröffentlichen.
